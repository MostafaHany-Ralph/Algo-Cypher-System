# 🔐 Algo Cypher System

## 📖 Overview

**Algo Cypher System** is a Python-based cryptography project that implements multiple encryption and decryption techniques.  
The system is designed for learning, experimenting, and extending classical and modern cipher algorithms within a unified and modular structure.

It also supports adding **new custom ciphers**, making it a flexible and extensible cryptography framework.

---

## ✨ Features

- 🔒 Multiple Cipher Implementations
  - Caesar Cipher
  - Vigenère Cipher
  - Substitution Cipher
  - (and more custom/advanced ciphers)

- 🔓 Encryption & Decryption support for all ciphers

- 🧩 Modular Design
  - Easy to add new cipher algorithms
  - Clean separation between logic and execution

- 📚 Educational Purpose
  - Helps understand cryptography fundamentals
  - Demonstrates how different encryption techniques work

- ⚙️ Extensible Architecture
  - Add your own cipher with minimal changes

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Basic Cryptography Concepts
